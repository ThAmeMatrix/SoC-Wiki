# 铃兰档案馆 · 离线 Wiki

基于 [BWIKI 铃兰之剑 Wiki](https://wiki.biligame.com/llzj) 的个人离线资料馆。快照日期：**2026-10-23（北京时间）**。

## 打开即可使用

**双击 `index.html`，或在 Windows 上双击 `start.cmd`。**

无需安装、账号、Node.js、Python 或网络。所有正文、搜索索引、样式、脚本和图片都在本地。推荐使用 Edge、Chrome 等现代浏览器。

如果使用压缩包，请先完整解压，再打开 `index.html`。请保留整个文件夹（包括 `assets/`、`data/` 和全部 `.js`、`.css` 文件），不要只复制首页。

**Android**：可安装 `release/SoCwiki-offline-1.18.0.apk`，支持 Android 8.0 及以上。APK 已内置所有离线资料和图片，无需解压或额外下载。初次安装时按系统提示允许当前文件管理器安装应用。收藏与笔记保存在应用中；卸载前请导出备份。构建说明见 `android/README.md`。

## 常用操作

- **搜索**：点击顶栏，或按 `Ctrl+K` / `/`。全站搜索输入即更新，中文输入确认后也会自动搜索，无需点击按钮；右侧「× 清空」有悬停、按下和键盘焦点反馈，清空关键词时保留筛选条件。支持角色别名、全文、模糊与语义匹配；直接输入「持续伤害」「驱散我方减益」「百分比伤害」可关联角色的技能、个性、各星级及抉择分支。用方向键选择结果，按 Enter 打开，Esc 关闭；点击「全部结果与筛选」进入全站搜索页，按分类、武器、多个阵营与命中位置继续筛选。
- **筛选与图鉴**：组合职业、阵营、稀有度或装备类型。角色默认显示像素小人，按原站角色图鉴的顺序排列，支持分页。可切换为含头像、像素形象、职业、阵营、武器与六项满级满星属性的“单位列表”；点击数值表头升降序排列，小屏可横向滚动，两种视图共享筛选条件。
- **角色立绘**：角色页直接切换初始立绘、觉醒立绘（五星）及已归档皮肤，点击立绘可放大和保存。原站缺少的立绘明确提示，不用其他图片冒充。
- **角色属性**：切换初始 / 满级满星属性，查看技能树、故事和原文。支持精英稀有度筛选；从原文补全旧式页面的属性，召唤物的继承属性按原值展示。
- **个性星级**：默认“五星对照”，公共效果单独展示，下方依次列出 1–5 星的其余完整文本。公共效果与该星文本共同构成完整个性。底色和下划线标记变化：1 星标出后续会成长的部分，后续星级标出相较上一已收录星级的调整；移除的文字另行标记。保留原文颜色和原有词条链接，也可切回“单星全文”。仅提取五个星级完全相同的完整句子作为公共效果，缺少星级时不推算。
- **技能成长树**：进入角色的“技能与成长”，技能树从下向上生长，11 阶在顶部、1 阶和初始技能在底部。1、3、5、7、11 阶呈左右分支，9 阶单列为普攻进阶。点选技能可在本页查看消耗、冷却、标色效果和范围图；桌面在右侧展示，小屏在选中节点下展开。
- **技能范围图**：成长树详情和技能独立页面均展示已归档的原站范围图，点击可放大。直接使用本地原图，缺图时不根据文字猜测形状。
- **装备**：切换 1–5 星技能效果，查阅来源与适合角色；在“装备属性参考”按类型、稀有度查看满级满星基础属性，并直接进入同类装备档案。
- **对比**：点击角色卡片的“加入对比”，最多并排比较 3 位角色。
- **一图流工坊**：从“离线工具”进入，按出场顺序或搜索选择角色。使用游戏 Logo、像素小人、中日 CV 和觉醒立绘。个性与专武展示完整 1→5 星效果，变化数值用 `/` 分隔并标红，尚未解锁的对应效果记为 `0`；固定效果只写一次，机制文字变化完整保留。没有觉醒立绘时明确提示并使用初始立绘。技能树自上而下为 11、9、7、5、3、1 阶与初始技能；初始两项仅展示，其他技能点击后按“未标记 → 必点 → 选点 → 未标记”循环，金色实线表示必点，青色虚线表示选点。技能搭配默认一套，可自由增删且至少保留一套；已有多套方案完整保留。每套含普攻（可选初始普攻）、反应和三项技能，箭头调整后三项顺序。可启用下方「搭配解说」，独立调整文本框位置、大小、字体、字号、行距、颜色、加粗、斜体、对齐和描边；关闭后隐藏成图区块并保留内容。武器、装具、22 张塔罗各有四个备选位，每项和每组下方都可填写居中红字说明。全部 10 种刻印共鸣支持多选，每组可填写独立解释；武器类型以客户端解析为准，「魔法武器」已统一为「法术」。右下角「角色评级」用六维雷达图呈现玩家评分，其下方为可自由编辑的「玩家评估」文字区域（旧版 0–5 评分数据兼容保留）；页脚「基础信息」以两列三行展示物攻 / 魔攻、物防 / 魔防、生命 / 速度的图标、当前值 / 可邂逅角色最高值、占比和进度条；最高值不含召唤物，当前值加粗高亮。移动与跳跃在底部横排，仅展示当前值，编辑区与导出图片一致。放大预览支持查看 / 调整布局模式，在放大画布里拖动、拉伸、输入坐标与尺寸，对齐磁吸、撤销 / 重做与普通预览同步。成图底部仅保留右下角 `by 制作人名字` 艺术署名。按角色保存独立草稿，支持 PNG 与方案 JSON 导出；旧版方案自动兼容。手机支持编辑 / 预览切换。需要备份草稿时，请在工坊内点击“保存方案”。
- **伤害计算**：从“离线工具”进入，实时计算普通 / 暴击伤害，查看职业克制、减防与伤害区间；支持保存 20 个方案、导出结果图片和导入 / 导出方案 JSON。
- **邂逅模拟**：初遇 / 重逢双卡池，单次、十连、100 次模拟；共享传说保底和独立 UP 保底，自动保存统计与最近 200 次记录，可导入 / 导出 JSON。
- **标色与词条**：技能、个性及原文保留颜色语义，适配明暗主题；可点击金色状态词条查看离线说明，鼠标悬停或键盘聚焦该词条时也会直接显示其效果说明。技能与个性详情的完整原文可展开。
- **收藏和笔记**：点击书签收藏；详情页笔记自动保存。数据仅存于当前浏览器。
- **长图**：点击原文图片，支持放大、适应窗口和本地保存。
- **阅读**：攻略支持字号调整、目录和专注阅读；字号自动记忆，支持深色主题和窄屏导航。原文中的角色属性面板可以切换，简单属性表支持点击表头排序。
- **备份**：在“资料馆信息”导出 / 导入收藏、笔记、浏览记录、角色对比、主题、字号、伤害方案和邂逅记录。更换浏览器、移动资料包或清理浏览器数据前建议备份。

浏览器对 `file://` 本地存储的处理可能不同。若页面提示保存受限，请导出个人备份。离线资料本身始终保存在文件夹中。

## 离线边界与来源

正文、图片、搜索和本地功能都无需联网。原文中的 Bilibili 视频、TapTap 文章及其他第三方网页保留原链接，打开它们需要联网。未下载外站视频、讨论页、用户页及历史修订全集。

伤害计算器和邂逅模拟器已按原站归档的公式、名单与规则重建为离线交互。原站 7523、8027 页面链接会自动打开对应工具。邂逅模拟使用快照卡池（初遇：薇佩拉；重逢：鲁特菲、爱莎），并非实时游戏卡池。非 UP 传说候选沿用原站模拟器排除两个池全部 UP 的方式；所有传说结果（含 180 次 UP 保底）均重置共享保底。详细规则在工具内可展开查看。

装备属性参考读取原站的满级满星属性表，共 24 组类型与稀有度组合，其中 7 组有有效记录，17 组在原表全填为 0，界面会明确标记。此表不包含装备技能加成，也不推算任意等级或星级的属性。原站评分计算草稿、装备成长计算占位代码未提供可靠公式，因此保留原始资料并标明测试性质；不补造结果。评论、视频及依赖服务器的服务仍不离线提供。

个人备份采用 v2 格式，仍兼容旧版 v1。导入时合并收藏、笔记、浏览记录、对比及计算方案；同一页面的笔记、同名计算方案以导入内容为准。邂逅记录完整替换当前模拟进度，需要与资料包的卡池版本一致。旧版备份不含工具数据时保留现有记录。导入文件先完整校验，再保存；损坏的工具参数会拒绝导入，避免覆盖有效数据。

游戏图片、角色设定与内容版权归原权利人所有。Wiki 资料来自 BWIKI 铃兰小站、灵灵妖攻略组及社区创作者；原文作者署名和出处保留。原站声明禁止将其资料用于商业用途，本项目用于个人离线查阅。

角色界面的信息层级与文字配色参考 [Soshage 角色页](https://soshage.com/soc/zh-tw/unit/223)，单位列表布局参考其 [单位目录](https://soshage.com/soc/zh-tw/unit)。角色排序、技能数值、描述、左右分支和范围图均使用本项目的 BWIKI 归档，页面运行时无需访问参考网站。

## 项目与更新

阅读无需依赖。以下命令仅供维护资料的开发者使用，需要 Python 3.10+ 和网络：

```powershell
python -m pip install -r requirements.txt
python scripts/sync_wiki.py --refresh --reparse
python scripts/sync_assets.py --refresh
python scripts/build_data.py
```

同步器使用公开 MediaWiki API，限速、重试并支持断点续传。`--reparse` 会重新渲染页面，从而覆盖模板变化。抓取失败会写入报告并返回非零状态；请先检查失败项，不要用不完整抓取覆盖交付快照。原始抓取不包含登录凭据。

`data/archive.json` 记录覆盖率和图片缺失项；`data/sources.json` 记录每页来源修订；`data/raw/recovered-assets.json` 记录本次旧图片路径的恢复依据。

前端使用原生 HTML / CSS / JavaScript，没有运行时第三方库。页面按需加载为本地脚本，避免 `file://` 的 fetch / CORS 限制。正文经过清洗，移除原站脚本、表单、事件处理器和远程嵌入；CSP 限制运行时联网与脚本执行。

## 一图流素材与构建

新增 `infographic-core.js`（选择规则）、`infographic-ui.js`（编辑器）、`infographic-canvas.js`（成图）、`infographic.css`。运行 `python scripts/build_infographic.py` 从既有离线数据提取塔罗、全部刻印共鸣、装备图标和完整五星对照文本，并生成 `data/infographic.js` 与 `data/infographic-assets/*.js`。技能与装备图标使用适当缩放副本，背景立绘使用原始分辨率的无损 WebP，通过本地脚本载入，不依赖服务器或网络，因此直接双击网页也能导出含立绘的 PNG。原图仍保留用于资料查阅。

验证：`node scripts/test_infographic.cjs`、`python scripts/test_infographic_stars.py`、`python scripts/verify_infographic.py`；Android 构建后执行 `python scripts/verify_android_bridge.py` 检查打包素材与保存桥接。

一图流成图顶部使用稀有度、职业与阵营的本地图标，角色名字和题签放大展示。技能加点以加粗实线圈 / 虚线圈区分必点与选点；装备红字备注随名称行数紧接排列。

一图流默认 **1920 × 1080**，可在「画布与整体风格」中自定义宽高（宽 480—4096、高 320—8192 px），或选择横版、竖版、方形预设。尺寸变化可自动重排区块，也可按比例保留自定义布局；预览、拖拽、背景编辑、PNG 与方案保存均使用实际画布尺寸。默认金色双层细边框、切角和细小角饰，可调整装饰强度或切回简洁青色边框。「一键凸显立绘主体」自动调整立绘构图，将信息区排列在主体两侧（竖版改为顶部展示立绘），内容较多时自动增加画布高度；全部选择与文字保留，并可撤销回原布局。布局模式的辅助框透明，坐标尺寸显示在画布外；按住空格可临时隐藏辅助线，放大预览可切换查看模式。技能树使用交替长短的直线分支，未标记节点置灰，顶端完整展示极限解放，树底可填写加点补充。薇佩拉名字使用用户参考图中提取的原字标，其他角色默认使用普通字体，可切换思源宋体或黑体，也可导入含名字的 PNG / JPG / WebP 图片自动提取透明字标；普通文字可在「角色名字颜色」中改色，图片默认保留原色，可选择随名字颜色着色；像素小人与紧邻的分类图标组成右上角人物信息。旧版方案可直接导入，新的颜色和树底文字随方案保存。文字过密时会提示增大画布或相应区块，避免信息难以阅读。

普通字体与识别资源准备：安装 `fonttools[woff]` 到 `.tools/python-fonts`，将 Adobe Source Han Serif SC Heavy 和其 OFL 放入 `.tools/fonts`，运行 `python scripts/build_title_import_assets.py` 后再运行 `python scripts/build_infographic.py --metadata-only`。构建脚本按固定版本获取 OCR 库与字库；生成的离线包无需网络。运行时通过本地 WOFF2 字库按输入文字绘制，无须设备安装字体或预先烘焙角色名。来源与许可证保存在 `assets/licenses/`。

## 本地客户端更新（SoCdecode 已并入本项目）

本地工具做两件事：**资源归档**——把本机铃兰之剑客户端里的全部资源解析成可直接查看的文件，按分类整理，并以解析时间记录版本、自动生成差分；**Wiki 更新**——把角色词条、技能、个性、专武与关联状态写入这个离线资料馆。解码逻辑在 `scripts/socdecode/`，网页与 APK 本身不需要 Python。

**图形界面（推荐）**：双击根目录 `本地更新.cmd`，或运行打包出的 `dist/SoCwiki本地更新.exe`。选择一次客户端目录与归档目录后会记住。界面分三页：

- **资源归档**：选择解析范围（12 个分类可单独勾选）与并行进程数，点「开始解析」。五个阶段（扫描 → 比对上次结果 → 解析 → 生成版本与差分 → 整理分类目录）实时显示进度条、吞吐量、剩余时间、新写入文件数与复用数；可随时取消，已完成的部分下次直接复用。与上一版本不同时以当前时间生成新版本并提示查看差分；完全相同则不生成。
- **版本库**：列出全部版本（时间、游戏资源版本、资源数、体积、新增 / 修改 / 删除 / 改名数、客户端文件变化、耗时）。选一个「浏览」，选任意两个「比较」，也可打开版本报告、导出分类目录、删除版本与清理未引用文件。
- **Wiki 更新**：差量更新（只补缺失与客户端新增角色，冲突以客户端为准）/ 全覆盖；检查新角色、预览差异、一键拉取、回滚上次更新。

**资源浏览器**（「打开资源浏览器」，或 `archive serve`，只监听 127.0.0.1）：左侧版本时间线（每个版本的变化徽标，一键设为基准 / 目标或对比上一版），中间分类树与可搜索、可分页的资源列表，右侧预览与差分。

- 预览：图片（棋盘格背景、原始大小）、配置表（分页、全文搜索）、文本 / JSON（行号）、视频、字体样张、模型线框（可旋转缩放）、二进制十六进制视图；可下载或在文件夹中定位原文件。
- 差分：版本概览按分类给出新增 / 修改 / 删除 / 改名与体积变化；图片支持并排、滑动对比、闪烁与差异高亮（标出变化像素数量与范围）；配置表按主键逐行、逐字段列出修改前后值，以及新增 / 删除的行与列；文本逐行并排对比并高亮行内改动；内容相同、路径不同的资源识别为改名；另列客户端原始文件的增删改。
- 地址栏保留当前版本、分类、筛选与选中资源，可直接分享或用前进 / 后退切换；`/` 聚焦搜索，`↑↓` 切换资源，`Esc` 回到概览；明暗主题。

**归档内容与分类**：配置表（全部 1,249 张客户端配置表解码为 JSON，含主键与行列数）、图片（Texture2D，PNG）、精灵（Sprite 裁切）、文本、数据（不可读的 TextAsset 与带容器路径的 MonoBehaviour 结构）、脚本（Lua 字节码）、音频（Wwise `.wem` / `.bnk`，客户端已加密，只做存档与变化比较）、视频（`.mp4`）、字体、模型（OBJ）、资源包清单（每个资源包的对象构成）、程序文件。当前客户端（资源版本 6265075，49,023 个文件，9.1 GB）解析为 177,277 项资源。账号记录、启动器数据库、战斗回放（`assets/Report`）与玩家偏好设置始终不读取。

**存储与性能**：每项资源按内容指纹只保存一份（`output/archive/objects/`，只读），版本只记录「路径 → 指纹」清单，因此多个版本共享未变的资源，新版本只占用变化部分的空间。`library/当前版本/` 是按「分类 / 位置 / 文件名」整理的目录，由硬链接组成，不额外占用空间，每次解析后只更新变化的文件；任意版本都可另外导出成同样的目录。解析在多进程中并行；每个客户端文件的解析结果按内容缓存，未变的文件不再解析。本机实测（20 线程 CPU）：首次完整解析 9.1 GB 约 5.5 分钟，首次建立分类目录另需约 3 分钟；客户端未变时重新检查约 2.5 秒；部分更新只解析变化的文件。

**命令行**：

```powershell
python -X utf8 scripts/update_client.py archive scan                 # 解析全部资源；有变化才生成新版本（--only table,image 只解析部分分类）
python -X utf8 scripts/update_client.py archive versions             # 列出全部版本
python -X utf8 scripts/update_client.py archive diff [基准] [目标]   # 比较任意两个版本（省略则为最新与上一版）
python -X utf8 scripts/update_client.py archive serve                # 打开资源浏览器
python -X utf8 scripts/update_client.py archive export <版本> [目录] # 把某个版本导出为分类目录（硬链接）
python -X utf8 scripts/update_client.py archive delete <版本>        # 删除版本记录；随后 archive gc 释放空间
python -X utf8 scripts/update_client.py characters --missing         # 客户端有、Wiki 还没有的角色
python -X utf8 scripts/update_client.py add --character 君士坦丁     # 导入一个角色（--dry-run 只看差异）
python -X utf8 scripts/update_client.py diff                         # Wiki 差量更新
python -X utf8 scripts/update_client.py full                         # Wiki 全覆盖
python -X utf8 scripts/update_client.py rollback "<备份目录>"        # 回滚一次 Wiki 更新
```

**打包成 exe**：

```powershell
python -m pip install -r requirements.txt pyinstaller
python -X utf8 scripts/build_client_updater.py      # 生成 dist/SoCwiki本地更新.exe（含资源浏览器）
```

**单元测试**（进入 `scripts` 目录后运行；覆盖属性截断、状态符号、转义、格式检查、幂等写入、失败恢复与回滚冲突，以及归档的分类与隐私排除、差分（改名识别、表格逐字段、文本分块）、版本生成、复用与清理）：

```powershell
cd scripts
python -X utf8 -m unittest discover -s socdecode/tests -v
```

**规则与边界**：需要 Windows x64 与 Python 3.10+；只读取客户端文件，不登录、不启动游戏。配置表在隔离的 Lua 环境中由客户端自带的运行库解码（无文件、进程与网络能力）。某个文件导致解析进程崩溃时会自动重启进程并逐个重试，仍失败的文件记入版本记录而不中断整个解析；无法解码的对象只记录指纹，同样参与比较。Wiki 更新每次写入前在 `output/backups/时间-编号/` 保存逐文件备份与变动报告，重复运行相同数据不会改动文件；写入失败自动恢复，`rollback` 只操作该次更新的文件。属性按客户端 `PlayerRoleUnit.CalculateAttributeByType` 的整数截断顺序计算（60 级、五星、13 阶、左右技能全解锁），不含装备、天赋、好感与模组加成。技能范围图只绘制字段或描述惯例能确定的形状。

**注意**：Wiki 更新会直接把新页面合并进 `data/index.js`、`data/search.js` 与 `data/advanced-search.js`。`scripts/build_data.py` 只从 `data/raw` 重建这些索引，会清掉客户端写入的条目，因此客户端更新后不要运行它（本工具自带的重建只跑 `scripts/build_infographic.py --metadata-only`）。`output/`（归档、缓存、报告、备份）已加入 `.gitignore`。
